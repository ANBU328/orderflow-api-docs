# OrderFlow API Documentation Portfolio

A portfolio project demonstrating professional API and developer documentation for a fictional B2B SaaS order-management platform.

> **Portfolio disclaimer:** OrderFlow is a fictional product created as a learning and portfolio project. No real customer, company, or production API is represented.

## What this project demonstrates

- REST API documentation
- OpenAPI 3.0 specification
- Authentication documentation
- Endpoint reference
- JSON request/response examples
- Error handling
- Pagination and filtering
- Webhooks
- Integration guides
- Release notes
- Docs-as-code workflow
- Git/GitHub and Markdown

## Learning path

1. Learn REST, HTTP methods, status codes and JSON.
2. Read the OpenAPI file.
3. Compare the OpenAPI operations with the Markdown endpoint pages.
4. Run the example cURL requests.
5. Edit an endpoint and update its example.
6. Add a new endpoint using the same documentation pattern.
7. Publish the repository with GitHub Pages or another static documentation host.
